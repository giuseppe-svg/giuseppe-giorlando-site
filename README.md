# Giuseppe Giorlando, personal site

Single-file site (`index.html`), no build step. Light paper background with a watercolor veil painting and form drawings (seals, roses, lemniscates, Cassini curves) generated in the browser. Each visit gets its own seed and a palette that follows the visitor's hour, so the page never looks the same twice.

Assets live in `assets/`: `og.png` for social previews, the app icons, and the three photos (`dj.jpg`, `surf.jpg`, `scuba.jpg`). Open the file in a browser or serve the folder with any static server.
